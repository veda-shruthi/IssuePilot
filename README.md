# IssuePilot

**Explainable AI-Based Software Issue Routing System**

## Overview
IssuePilot is a final-year academic major project intended to help
classify software issues and route them to the appropriate team.

## Planned Features
- Software issue classification
- Suggested team assignment
- Explanations for routing predictions
- Evaluation of classification performance

## Planned Technology Stack
- Python
- Machine learning
- Explainable AI techniques

## Project Status
In development — implementation has not yet started.

## Author
Student project developed as part of a B.Tech major project.
